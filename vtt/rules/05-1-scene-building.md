# The Bullpen: Scene Building (SCRPG Core Rulebook, Ch. 5)
**Source pages:** 183–203 | **Golden Rule:** Borrow and reskin!

## Action Scenes: Fundamentals
Two goals: (1) Every hero has something to do each turn; (2) Clear sense of challenge.

### Scene Difficulty
- **Easy:** Introductory; no villain or minor threat; don't let drag.
- **Moderate:** Bulk of campaign; tax heroes somewhat; villain or environment possible.
- **Difficult:** Capstone scenes; both villain & environment likely; extended play ok if epic.

### Number of Elements
Scene contains **Ⓗ** scene elements (where Ⓗ = number of heroes).

### Difficulty by Element Type
- **Easy challenges:** 1–2 successes OR 1 + advanced difficulty
- **Moderate challenges:** 3–4 successes OR 1–2 + advanced difficulty
- **Hard challenges:** 5+ successes OR 3–4 + advanced difficulty

**Minions (by difficulty):**
- Easy: Ⓗ × d6
- Moderate: Ⓗ × d8
- Difficult: Ⓗ × d10

**Lieutenants:** ½Ⓗ (half heroes, rounded up)
- Easy: ½Ⓗ × d8
- Moderate: ½Ⓗ × d10
- Difficult: ½Ⓗ × d12

**Villains:** Each counts as moderate (no upgrades) or difficult (with upgrades); extra upgrades = +1 moderate element each.

**Environments:** Standard = moderate; all-hostile = difficult; max 1 per scene usually.

### Scene Trackers
**Confirmed counts (not what the book's text implies at a glance — see CLAUDE.md, this was already
checked against the physical book once; don't "correct" these back):**
- **Standard:** 2 Green, 4 Yellow, 2 Red (most common)
- **Prolonged:** 3 Green, 5 Yellow, 3 Red (longer scenes)
- **Epic:** 1 Green, 3 Yellow, 4 Red (final confrontations — minimal Green, several Red)

## Challenges
Simple: Describe obstacle, note on card. Don't detail solution paths — let players choose.

### Easy Challenges
1 successful Overcome action resolves. Example obstacles: crumbling office, meteor, non-powered thugs, hacked truck, bystander in crossfire, CCTV system.

### Complex Challenges
Multi-step (2–3 successes typical, max 5).

### Advanced Challenges

**Timed:** Add timer. Guidelines:
- Limited impact: 1–2 turns
- Major impact: Scene status change
- Catastrophic: See Doomsday Devices

**Conditional:** Multiple mutually-exclusive approaches w/ different outcomes.

**No-Win Scenarios:** Avoid pre-planning; let play emerge naturally. Use risky actions when heroes want to do more.

**On Failure:** Hero makes no progress; scene tracker advances; major setback but not game-over.

### Linked Challenges & Escalation
Chain challenges so resolving one unlocks next. Escalated twists reward risk: shorter path = higher-tier twists available.

## Notes
- Challenges can represent non-combat threats
- Mix it up: some scenes heavy on Overcome, others on Attack
- Challenge cards placed on table for all to see
- No need for minions if challenge fits story better
